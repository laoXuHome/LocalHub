127.0.0.9 返回 80KiB，超过 DefaultMaxBodyBytes=64KiB，因此即使 HTTP 200 也判为
probe_error，不误报成功。127.0.0.10 为计数服务器，探测后 `/__count` 返回 0，

## 5. 防重复触发

第一次 POST 返回 202：
  {"id":"probe-f26e9bb336fba7f3","status":"running","results":[]}
紧接着第二次 POST 返回 409：
  HTTP/1.1 409 Conflict
  {"error":"probe_in_progress","message":"已有探测正在进行，请等待完成",
   "run_id":"probe-f26e9bb336fba7f3","status":"running"}
未出现第二个 run，也不会堆积任务。
原始响应：duplicate-first.json、duplicate-headers.txt、duplicate-second.json、duplicate-completed.json

## 6. 状态语义

- 成功仅接受 HTTP 2xx。
- 3xx/4xx/5xx -> http_error，并记录 HTTP 状态码。
- 连接拒绝 -> connection_failed；先 HTTP，仅连接层失败才尝试 HTTPS。
- 超时 -> timeout。
- 响应体超限、读取异常、地址校验失败 -> probe_error。
- 无结果或结果地址与当前配置不一致 -> not_probed。
- 当前配置禁用 -> disabled，不读取旧结果、不发请求。
