## 二、接口

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/admin/bookmarks/import/preview` | 管理员 | 请求 `{format,data_base64}`；返回预览，**不写库** |
| POST | `/api/admin/bookmarks/import/execute` | 管理员 | 追加 `duplicates`、`selected`、`decisions`、`import_icons`；写库并返回汇总 |
| GET | `/api/admin/bookmarks/export` | 管理员 | `format=json|html`、`scope=all|selected`、`ids`、`visibility`；附件下载 |

`format` 支持 `auto/html/sunpanel/localhub`；`data_base64` 上限按解码后 10 MiB 控制。HTML/JSON 导出均带 `Content-Disposition` 与 `X-Content-Type-Options: nosniff`。

## 三、关键实现

### 导入管线

1. 解码并校验大小 → `Detect` 识别格式（JSON 的 `format=localhub-bookmarks` 判 LocalHub，其余 JSON 按 Sun-Panel；含 `<DL`/Netscape doctype 判 HTML）。
2. 解析为统一 `Record`，保留文件夹名用于预览展示。
3. `AnalyzeRecords` 逐条 `bookmark.Build` 校验，并按归一 URL 与已有数据、批内数据比对，产出 `new/duplicate/invalid`。
4. 预览只读返回；执行时重新解析同一文件，按 `selected`/`decisions` 逐条创建、覆盖或跳过。
5. 每条记录独立写库；单条失败不影响其他记录，也不回滚已成功项。
6. 内嵌图标先 `icon.Validate`；合法才落盘并 `SetIcon`，非法则书签照常导入、计入 `icons_failed` 并告警。

### 覆盖语义

`overwrite` 仅覆盖来源实际提供的字段：HTML/Sun-Panel 不携带权限、启用态与打开方式时保留原值，避免把 `private` 书签意外改成 `public`。JSON 携带全部字段则整体替换。图标切换为非 `file` 时删除旧文件；切换/覆盖为内嵌图标时重写文件。

### 导出

- JSON：完整字段 + 图标 base64。图标文件缺失时置 `icon_missing=true` 并告警，不导出路径。
- HTML：浏览器兼容 Netscape 格式；权限/启用/打开方式/描述/图标类型与值以 `LOCALHUB_*` 属性保留；二进制图标不写入 HTML（浏览器格式不支持）。
- 过滤在内存完成，导出全程不写库。

### 安全

- 三个端点均管理员鉴权，访客 401。
- 请求体经 `MaxBytesReader` 限制；解码后再校验 10 MiB。
- 导入不使用用户文件名，图标文件名由服务端生成，无路径穿越面。
- 导入不发起任何外网请求；`icon_type=favicon` 不会在本批触发抓取，因此不引入新的 SSRF 面。
- HTML 中 `javascript:` 等非 http/https URL 被 `bookmark.Build` 拒绝，计入 `invalid/failed`。
- 图标仅接受 P2.2 已验收的 PNG/JPEG/GIF/ICO，≤256 KiB、≤1024 px、≤1M 像素。

## 六、未完成事项与限制

1. **文件夹层级不写库**：数据模型无文件夹/分类字段，任务书同时禁止新增分类体系；本批仅在预览展示并在导入时给出 `folder_not_persisted` 警告。因此 HTML 导出也只能输出单一 `LocalHub` 根文件夹，无法还原来源层级。
2. **Chrome/Edge HTML 不携带 LocalHub 权限**：导入按 P2.1 默认 `public`，并给出 `html_permission_default` 警告；管理员应在导入后按需调整权限。
3. **HTML 不迁移二进制图标**：浏览器书签格式不支持内嵌图标文件；仅保留 `emoji/text/url` 图标信息。完整图标迁移走 LocalHub JSON。
4. **Sun-Panel 字段覆盖有限**：仅映射名称、URL、LAN URL、描述、图标、打开方式；权限、排序、文件夹不写入，已给 `sunpanel_partial` 警告。
5. **无前端页面**：按任务书不在本批开发；接口已可供后续前端调用。
6. **未做布局数据导入导出**：按要求明确排除。

以上均未修改 P0/P1.1/P2.1/P2.2 已验收行为，未启动 P2.4 或 P3。
