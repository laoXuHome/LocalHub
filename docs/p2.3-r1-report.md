4. LocalHub JSON 导出必须能够保留文件夹层级，并支持再次导入恢复。

## 三、实现方案

### 3.1 数据模型与迁移

- 新增迁移 `internal/db/migrations/0005_folder.sql`：

```sql
ALTER TABLE bookmarks ADD COLUMN folder_path TEXT NOT NULL DEFAULT '[]';
```

- `bookmarks.folder_path` 保存 JSON 字符串数组，例如 `["工作","项目A"]`；空数组 `[]` 表示根层级。
- 不新建文件夹表、分类表或标签表，层级只是书签路径的一部分。
- `Bookmark` 新增 `Folder []string`；API 输入/输出新增 `folder_path`。
- 路径校验：最多 16 级；每级最多 128 字节；禁止空段、换行与 NUL；输入去首尾空白。
- PATCH 语义：未提供 `folder_path` 时保留原值；显式 `[]` 表示移到根层级。

### 3.2 导入解析

| 来源 | 层级处理 |
| --- | --- |
| Chrome HTML | 按 `<H3>` / `</DL>` 事件顺序维护栈，保存完整多级路径 |
| Edge HTML | 与 Chrome 同格式；使用独立多级 fixture 验证 |
| 压缩成单行的 HTML | 改为全文档事件扫描，多个 `<H3>` 不再因逐行解析丢失 |
| Sun-Panel | 有名称、无 URL、含子节点的对象识别为分组；`groupName/folderName` 也作为层级 |
| LocalHub JSON v2 | 读取 `folder_path`，含显式空数组 |
| LocalHub JSON v1 | 没有 `folder_path`，按“来源未提供层级”处理：覆盖导入保留原层级，新建落根层级 |

### 3.3 预览与执行

- 预览结果中的 `Record` / `Item` 携带 `folder_path`，前端可展示完整层级。
- 预览接口只解析和判定，不写数据库。
- 确认执行时才通过 `bookmark.Build` 和 `Store.Create/Update` 写入 `folder_path`。
- 覆盖导入时：来源明确提供层级则采用来源路径；来源未提供（v1 JSON）则保留原路径。
- 重复检测、权限校验、图标迁移仍复用原逻辑，没有另起一套写入路径。

### 3.4 导出

- LocalHub JSON：格式版本从 `1` 升到 `2`，每条书签输出 `folder_path`；根层级输出显式 `[]`，不是 `null`；解析兼容 `1..2`。
- HTML：按已保存的 `Folder` 建树，递归输出嵌套 `<H3>` / `<DL>`；不再额外插入 `LocalHub` 根文件夹，避免导出再导入多一层前缀。
- 根书签直接输出在顶层 `<DL>`；文件夹按其首次出现顺序输出，文件夹内书签保持原排序。
- 本地图标仍不写入 HTML；JSON 图标 base64 逻辑未改。

### 3.5 无法映射层级的告警

| 情况 | 处理 |
| --- | --- |
| HTML 文件夹名为空 | 映射为“未命名文件夹”，并给出 `folder_unnamed` 告警 |
| Sun-Panel 分组缺少名称 | 子项放入上一级，并给出 `sunpanel_folder_unnamed` 告警 |
| 路径为空段/超长/含换行 | `bookmark.Build` 拒绝，导入条目记为失败并返回原因 |
| 层级超过 16 级 | HTML/Sun-Panel 解析直接报错，不静默截断 |
| HTML 层级未持久化 | 已移除旧的 `folder_not_persisted` 警告，因为该限制已修正 |

## 六、已知限制

1. **不保存空文件夹**：层级依附于书签，没有书签的空目录不会单独存在。
2. **层级上限**：最多 16 级、每级 128 字节；更深或更长的来源会被拒绝并返回原因。
3. **Sun-Panel 结构识别有限**：只识别约定的容器键和“有名称、无 URL、含子节点”的分组；未命名分组会告警并上移子项；JSON 嵌套保护为 12 层，早于 16 级路径上限。
4. **HTML 导出顺序**：同一层级下先输出子文件夹，再输出根书签；层级正确，但视觉顺序可能与原列表不同。
5. **HTML 不迁移二进制图标**：Netscape HTML 不支持；图标完整迁移仍走 LocalHub JSON。
6. **JSON 格式升级到 v2**：旧 v1 仍可导入；依赖 v1 固定版本号的外部脚本需要适配。
7. **无文件夹管理 UI**：仍只有后端接口；没有分类/标签、拖拽、文件夹 CRUD 或首页 UI。
8. **旧数据不回溯**：已有 P2.3 之前导入的书签默认根层级，原层级若当时未保存则无法恢复。
9. **同名同路径合并**：HTML 导出按路径建树，同一父级下同名文件夹视为同一节点；不同路径的同名文件夹仍可区分。
