## 1. 实现概览

### 1.1 数据与存储

- 迁移 `0004_icon.sql` 为 `bookmarks` 增加 `icon_file`、`icon_mime`、`icon_size`、`icon_updated_at`，不改动既有列与旧数据；迁移版本化执行，可重复调用。
- 图标文件固定存放于 `<DATA_DIR>/icons`（P0 已创建的持久化目录，容器内为 `/data/icons`），不使用临时目录、不依赖任何第三方云存储。
- 文件名为 `<书签ID>-<内容SHA256前8字节><扩展名>`，完全由服务端生成，用户输入不参与命名；写入使用临时文件 + `rename`，避免半截文件被读取。
- 数据库只保存内部文件名与 mime/大小，外部无法指定路径；`icon.Store.Path` 拒绝分隔符、`..`、隐藏文件与非白名单扩展名。

### 1.2 图标接口

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/bookmarks/{id}/icon` | 按书签权限 | 返回本地图标；访客仅公开书签可见，越权/缺失/损坏统一 404 |
| PUT | `/api/admin/bookmarks/{id}/icon` | 管理员 | 原始图片字节上传；替换旧图标并清理旧文件 |
| DELETE | `/api/admin/bookmarks/{id}/icon` | 管理员 | 清除图标关联并删除本地文件 |
| POST | `/api/admin/bookmarks/{id}/favicon` | 管理员 | 从书签 WAN/LAN URL 重新抓取，失败 502 不改动现有图标 |

书签 JSON 新增 `has_icon`，有图标时附带 `icon_url`（`/api/bookmarks/{id}/icon`）、`icon_mime`、`icon_size`。`icon_type` 新增内部值 `file`，只允许由图标接口写入，API 显式传 `icon_type=file` 会被 400 拒绝。

- 创建/编辑书签时若 `icon_type=favicon`，在响应返回后启动后台抓取，不阻塞管理请求；失败只记录日志并保留原状态。
- 书签删除（单个/批量）会清理该 ID 的全部图标文件；书签从本地图标切换为 emoji/text/url 时也会清理文件与元数据。

### 1.3 文件校验

| 项目 | 规则 |
| --- | --- |
| 大小 | 单文件 ≤ 256 KiB（上传与抓取同一上限，超限 413 / 抓取失败） |
| 格式 | 仅 PNG / JPEG / GIF / ICO；SVG、HTML、WebP、随机字节一律拒绝 |
| 内容 | 魔数 + 标准库 `image.DecodeConfig` 解码校验；ICO 校验目录项数量与尺寸 |
| 尺寸 | 单边 ≤ 1024，总像素 ≤ 1,048,576，防解压炸弹 |
| 文件名 | 服务端生成，禁用路径穿越；损坏/缺失文件只降级为 404 |
| 响应头 | `X-Content-Type-Options: nosniff`、`Content-Security-Policy: default-src 'none'`、ETag、按权限设置 Cache-Control |

### 1.4 Favicon 抓取与 SSRF 防护

抓取器 `internal/favicon.Fetcher` 的防护点：

1. 仅允许 `http/https`，拒绝 `file/gopher/ftp` 等协议；URL 必须有主机名。
2. 不读取环境代理（`Proxy=nil`），避免通过代理绕过地址检查。
3. 自定义 `DialContext`：先解析域名并逐个检查全部 IP，再直接拨解析出的 IP，规避 DNS rebinding 二次解析。
4. 拒绝回环（127/8、::1）、私有（10/8、172.16/12、192.168/16）、链路本地与云元数据（169.254/16、fe80::/10）、IPv6 ULA（fc00::/7）、运营商级 NAT（100.64/10）、未指定、组播、保留/文档/基准测试网段，以及 IPv4 映射回环。
5. `CheckRedirect` 逐跳校验协议与解析地址，最多 5 跳；页面内提取的 icon 链接同样走完整校验。
6. 响应限制：页面 ≤ 512 KiB、图片 ≤ 256 KiB；只接受 `image/*` 或 HTML；总超时 10s、连接/响应头 5s。
7. 抓取结果再次经过 `icon.Validate`，非法内容不落盘。

## 6. 未完成事项及原因

1. Chrome/Edge、Sun-Panel、LocalHub JSON 导入与 JSON/HTML 导出未实现，按任务书留待后续批次。
2. 书签管理前端页面、首页书签网格与 UI/UX 未改动，属后续批次。
3. LAN/WAN 自动探测、Docker 容器发现与状态关联未实现。
4. 多用户与分享授权未实现。
5. 图标只接受 PNG/JPEG/GIF/ICO，不支持 WebP 与 SVG；SVG 存在脚本风险，WebP 缺少标准库尺寸校验，均按安全优先拒绝。
6. 由于 SSRF 禁止访问内网/回环地址，**局域网书签（如 192.168.x.x）无法自动抓取 Favicon**，只能手动上传图标；这是安全约束下的预期行为。
7. 图标不做自动缩放/转码，超过 1024px 或 256 KiB 的图片需用户自行处理。
