# P5.1 Docker Socket Proxy 配置与安全说明

本文件说明 LocalHub 如何以只读方式访问 Docker，以及部署者需要调整的配置。P5.1 只建立连接与安全基线，不提供容器启停、删除、创建、命令执行、镜像/网络/卷管理或日志入口。

## 1. 连接关系

```text
LocalHub 容器
  └─ HTTP GET /version
       └─ docker-socket-proxy:2375（内部网络 docker-proxy）
            └─ /var/run/docker.sock（容器内只读挂载）
                 └─ 宿主机 Docker Engine
```

- LocalHub 容器**不挂载** `/var/run/docker.sock`，只能通过 Proxy 的 HTTP 接口访问 Docker。
- Proxy 以 `wollomatic/socket-proxy:1.14.0` 运行，Docker Socket 以 `:ro` 挂载。
- Proxy 只加入内部网络 `docker-proxy`，只 `expose 2375`，不发布宿主机端口。
- LocalHub 同时加入默认网络和 `docker-proxy` 网络。

## 2. 配置项

### LocalHub

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `LOCALHUB_DOCKER_API_URL` | `http://docker-socket-proxy:2375` | Docker API 地址。留空表示不启用 Docker 集成，状态为 `not_connected`。只接受 `http://`、`https://`、`tcp://`（`tcp://` 会归一化为 `http://`）。拒绝 `unix://`、URL 用户信息、路径、查询参数和片段。 |
| `LOCALHUB_DOCKER_TIMEOUT` | `3s` | 单次状态检测超时，允许 500ms–30s。 |

连接地址不写死宿主机路径或固定 IP。部署者可通过 `.env` 或 Compose 覆盖，例如：

```dotenv
LOCALHUB_DOCKER_API_URL=http://docker-socket-proxy:2375
LOCALHUB_DOCKER_TIMEOUT=3s
```

### Socket Proxy

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `LOCALHUB_DOCKER_PROXY_IMAGE` | `wollomatic/socket-proxy:1.14.0` | Proxy 镜像版本。 |
| `LOCALHUB_DOCKER_GID` | `999` | 宿主机 `/var/run/docker.sock` 所属组的 GID。Proxy 以 UID/GID `65534` 运行，需要该补充组才能读取 Socket。**部署前应改成实际值**。 |
| `LOCALHUB_DOCKER_PROXY_ALLOWFROM` | `localhub` | 允许访问 Proxy 的来源。默认只允许 Compose 网络中的 `localhub` 服务。 |

获取 Socket 组号：

```sh
stat -c '%g' /var/run/docker.sock
```

也可用：

```sh
ls -ln /var/run/docker.sock
```

将输出的组号写入 `.env`：

```dotenv
LOCALHUB_DOCKER_GID=107
```

如果组号不匹配，LocalHub 会得到 `connection_failed` 或 `permission_denied`，但主程序、书签等既有功能不受影响。

## 3. 只读 API allowlist

Proxy 只允许以下请求，其余请求在 Proxy 层被拒绝：

| 方法 | 路径 |
|---|---|
| `GET` | `/version` |
| `GET` | `/_ping` |
| `GET` | `/containers/json` |
| `GET` | `/containers/<id>/json` |
| `GET` | `/v1.<n>/version` |
| `GET` | `/v1.<n>/_ping` |
| `GET` | `/v1.<n>/containers/json` |
| `GET` | `/v1.<n>/containers/<id>/json` |
| `HEAD` | `/_ping` |

未配置 `POST`、`PUT`、`PATCH`、`DELETE` 等方法的 allowlist，因此写请求默认全部拒绝。容器和镜像 ID 只允许字母、数字、下划线、点和短横线。

被明确拒绝的示例：

- `POST /containers/create`
- `POST /containers/<id>/start|stop|restart|kill`
- `DELETE /containers/<id>`
- `POST /containers/<id>/exec`
- `DELETE /images/<id>`
- `POST /networks/create`
- `POST /networks/<id>/connect|disconnect`
- `GET /containers/<id>/logs`
- `GET /images/json`

LocalHub 当前代码只调用 `GET /version`。allowlist 中的容器只读端点预留给 P5.2 的只读发现，但 P5.1 不实现容器列表、容器详情或状态展示。

## 4. 部署

```sh
cp .env.example .env
# 编辑 .env，至少设置 LOCALHUB_DOCKER_GID
docker compose up -d
docker compose ps
```

LocalHub 默认端口 `11030`。打开“服务”入口即可看到 Docker 连接状态。

如果暂不需要 Docker 集成，可将地址留空：

```dotenv
LOCALHUB_DOCKER_API_URL=
```

LocalHub 仍会正常启动，状态显示“未连接”。

## 5. 状态含义

| 状态 | 触发条件 | UI 颜色 |
|---|---|---|
| `connected` | `GET /version` 返回 200，且 JSON 含 `ApiVersion` 与 `Version` | 绿色 `#16A34A` |
| `not_connected` | 未配置地址 | 灰色 `#9CA3AF` |
| `connection_failed` | 连接被拒绝、DNS 失败、超时 | 红色 `#DC2626` |
| `permission_denied` | Proxy 或上游返回 401/403 | 红色 `#DC2626` |
| `service_unavailable` | Proxy 返回 502/503/504 | 红色 `#DC2626` |
| `unknown` | 其他状态码或非法 JSON | 深灰色 `#6B7280` |

状态接口为 `GET /api/admin/docker/status`，仅管理员可访问；访客返回 401。响应只包含 `status`、`api_version`、`checked_at`、`message`、`read_only`，不包含连接地址、Socket 路径、上游响应体或内部错误堆栈。

## 6. V-02 写操作拒绝验证

脚本：

```sh
P51_DOCKER_PROXY_URL=http://docker-socket-proxy:2375 \
P51_ARTIFACT_DIR=/tmp/p51-v02 \
sh scripts/p51-v02.sh
```

脚本真实发送 11 项写请求，要求全部 HTTP ≥ 400；同时验证 2 项只读请求为 200、2 项未授权只读请求为 403。任何写请求成功都会使脚本退出非零。

CI 在 LocalHub 的网络命名空间内执行同一脚本：

```sh
docker run --rm --network container:localhub \
  -e P51_DOCKER_PROXY_URL=http://docker-socket-proxy:2375 \
  -e P51_ARTIFACT_DIR=/out \
  -v "$PWD/scripts:/scripts:ro" \
  -v "$PWD/ci-artifacts/p51-v02:/out" \
  --entrypoint sh curlimages/curl:8.11.1 /scripts/p51-v02.sh
```

## 7. 常见问题

- **状态 `connection_failed`**：检查 `LOCALHUB_DOCKER_API_URL` 是否指向 Proxy、Proxy 是否运行、两者是否在同一网络。
- **状态 `permission_denied`**：检查 `LOCALHUB_DOCKER_GID` 是否等于 `stat -c '%g' /var/run/docker.sock`。
- **状态 `service_unavailable`**：Proxy 可达，但宿主机 Docker Engine 未运行或不可用。
- **不要**为了排障把 `/var/run/docker.sock` 挂载进 LocalHub，也不要临时开放完整 Docker API；这会绕过 P5.1 的安全边界。
