# 结论
1. 只有 docker-compose.yml 的 docker-socket-proxy 服务只读挂载 Docker Socket。
2. localhub 服务的 volumes 只有 LOCALHUB_DATA_DIR -> /data，没有 Docker Socket。
3. Go 代码没有 unix:// Docker 客户端；配置校验拒绝 unix://。
